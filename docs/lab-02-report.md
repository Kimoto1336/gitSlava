# Отчёт по ЛР №2

**Проект:** Славянский круг — гид по славянским мифологиям.  
**Цель:** создать главную страницу и вывести данные из mock-источника.

Главная содержит название, навигацию, краткое описание, показатели библиотеки и карточки статей. Данные хранятся в `src/mocks/data.ts`; главная получает коллекцию с имитацией задержки. `useState` хранит полученные материалы и состояние загрузки, `useEffect` запускает загрузку при открытии страницы и очищает таймер при размонтировании.

Компоненты: `Shell`, `Heading`, `Card`, `Home`, страницы каталога, статьи и редактора. Запуск: `npm install`, `npm run dev`; сборка: `npm run build`.
