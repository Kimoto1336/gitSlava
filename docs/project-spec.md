# Спецификация проекта

## Пользователь и проблема
Читатель, студент или любитель фольклора, которому нужно систематизировать и находить материалы о славянских мифологических образах.

## Основная сущность — статья
Поля: `id` (уникальная строка), `title` (строка), `description` (многострочный текст), `category` (категория), `status` (статус), `amount` (число заметок), `date` (дата), `isActive` (логическое поле), `region` (традиция), `symbol` (символ), `tags` (ключевые слова).

## Страницы
| URL | Назначение |
|---|---|
| `/` | Обзор, сводные показатели и новые статьи |
| `/encyclopedia` | Поиск и сортировка всей коллекции |
| `/article/:id` | Подробная статья, избранное, редактирование и удаление |
| `/create` | Создание статьи с проверкой обязательных полей |
| `/edit/:id` | Редактирование статьи |
| `/statistics` | Сводные показатели и экспорт JSON |
| `/deities` | Каталог божеств |
| `/spirits` | Каталог духов |
| `/rituals` | Каталог обрядов |
| `/regions` | Обзор региональных традиций |
| `/favorites` | Сохранённые статьи |
| `/search` | Поиск по заголовку, описанию и тегам |
| `/about` | Назначение и принципы проекта |
| `/import` | Импорт коллекции JSON |
| `/concepts` | Каталог понятий |
| `/characters` | Каталог сказочных персонажей |
| `/timeline` | Хронологический список по дате обновления |
| `/guide` | Дополнительный информационный маршрут |

## Пользовательские сценарии
1. Открыть обзор и перейти к энциклопедии.
2. Найти статью поиском и открыть подробную страницу.
3. Добавить статью в избранное и открыть список избранного.
4. Создать статью, заполнить обязательные поля и сохранить.
5. Отредактировать существующую статью.
6. Удалить ненужную статью после подтверждения.
7. Отфильтровать материалы по тематическому разделу и отсортировать.
8. Просмотреть статистику и экспортировать JSON.
9. Импортировать JSON-файл в библиотеку.

## Состояние и данные
Используется демонстрационная коллекция из 12 статей. Основное состояние управляется Redux Toolkit. Mock-данные используются без backend; на главной странице загрузка имитируется задержкой и обрабатывается через `useState`/`useEffect`.

## Ограничения первой версии
Нет backend, аккаунтов, синхронизации между устройствами, полноценной системы источников и редакторской модерации. Данные Redux живут в памяти вкладки; постоянное сохранение в localStorage можно добавить отдельным этапом.
